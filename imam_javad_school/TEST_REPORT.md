# گزارش آزمون نسخه یکپارچه

تاریخ ساخت: 2026-11-20

## بررسی‌های ایستا

- `python -m py_compile app.py config.py create_admin.py backup.py legacy_import.py backend/*.py` — موفق
- `node --check frontend/js/app.js` — موفق؛ Node فقط ابزار توسعه است و برای اجرای برنامه نیاز نیست.

## آزمون‌های HTTP در پایگاه داده موقت

- ورود مدیر اولیه — موفق
- جلوگیری از استفاده از API پیش از تغییر رمز اولیه (HTTP 428) — موفق
- تغییر رمز و ورود مجدد — موفق
- ایجاد کلاس و حساب دانش‌آموز — موفق
- ثبت اطلاعیه — موفق
- ثبت برنامه هفتگی، برنامه روزانه، بانک سؤال، آزمون، گزارش کلاس و مسئولیت — موفق
- ثبت و ویرایش فرم فعالیت — موفق
- ثبت کارنامه و محاسبه میانگین — موفق
- تهیه نسخه پشتیبان — موفق
- پیش‌نمایش ورود CSV — موفق
- دریافت سؤال آزمون بدون ارسال پاسخ صحیح به دانش‌آموز — موفق
- شروع آزمون، ثبت پاسخ، مشاهده پاسخ‌نامه و تصحیح دستی سؤال تشریحی — موفق
- بازیابی نسخه پشتیبان و بازگشت مقدار تنظیمات به نسخه ذخیره‌شده — موفق
- بسته‌شدن اتصال SQLite در پایان بلوک‌های مدیریت پایگاه داده برای جلوگیری از نشت اتصال — اصلاح و آزمون شد.

## آزمون‌هایی که هنوز انجام نشده‌اند

- اجرای واقعی روی Windows 7 و نسخه‌های مشخص Linux سبک
- آزمون چندکاربره و فشار روی لپ‌تاپ با RAM حدود 1.25GB
- آزمون نفوذ مستقل و انتشار امن اینترنتی
- تست مرورگرهای قدیمی و دستگاه‌های واقعی مدرسه
- ویرایش کلاس از API و ویرایش فرم فعالیت — موفق.
- خواندن قالب XLSX نمونه و پیش‌نمایش ردیف‌ها با تجزیه‌گر استاندارد کتابخانه Python — موفق.
