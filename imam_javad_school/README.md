# سامانه جامع مدیریت و ارتباطات دبیرستان دوره اول امام جواد (ع)

این پروژه نسخه محلی و چندسکویی سامانه مدرسه است. Backend با Python و کتابخانه استاندارد، پایگاه داده با SQLite و رابط کاربری با HTML/CSS/JavaScript خالص پیاده‌سازی شده است. هدف، اجرای سبک روی لپ‌تاپ کم‌قدرت و استفاده در شبکه داخلی بدون اینترنت است.

## سازگاری و پیش‌نیازها

- **Windows 7:** Python 3.8.x (ترجیحاً نسخه ۳۲ بیتی در صورت نصب ویندوز ۳۲ بیتی). Python 3.9 به بعد روی Windows 7 پشتیبانی رسمی ندارد.
- **Linux:** Python 3.8 یا جدیدتر به همراه ماژول SQLite.
- هیچ بسته Python خارجی، Node.js، Docker یا سرویس دیتابیس جداگانه لازم نیست.
- برای اجرای روزمره اینترنت لازم نیست.

## راه‌اندازی اولیه

### Windows

1. ZIP را در یک پوشه قابل نوشتن استخراج کنید.
2. Python 3.8 را نصب کنید و در صورت وجود گزینه، Python را به PATH اضافه کنید.
3. در پوشه پروژه `run_windows.bat` را اجرا کنید.
4. برای بار اول، در CMD داخل همین پوشه اجرا کنید: `python create_admin.py` و نام کاربری و رمز مدیر را خودتان تعیین کنید.
5. دوباره `run_windows.bat` را اجرا و در مرورگر به `http://127.0.0.1:8080` بروید.

### Linux

1. ZIP را استخراج کنید.
2. در ترمینال وارد پوشه پروژه شوید.
3. در صورت نیاز اجرا کنید: `chmod +x run_linux.sh`.
4. مدیر اولیه را بسازید: `python3 create_admin.py`.
5. اجرا کنید: `./run_linux.sh`.
6. در مرورگر به `http://127.0.0.1:8080` بروید.

حساب مدیر اولیه باید در نخستین ورود رمز خود را تغییر دهد. رمز پیش‌فرضی در کد وجود ندارد.

## امکانات پیاده‌سازی‌شده

- ورود و خروج با نشست سمت سرور، هش PBKDF2-HMAC-SHA256، CSRF، انقضای نشست، محدودیت تلاش ناموفق و الزام تغییر رمز اولیه.
- نقش‌های مدیر، دانش‌آموز، دبیر، مسئول پایه و معاونت‌های مالی، نظامت، آموزشی، پرورشی، پژوهشی و رسانه؛ مجوزهای مستقل و کنترل سمت سرور.
- مدیریت کاربران، غیرفعال‌سازی، بازنشانی رمز، تعیین نقش و مجوز، خروجی CSV و ورود گروهی CSV و XLSX با پیش‌نمایش و اعتبارسنجی.
- مدیریت پایه/کلاس و پرونده دانش‌آموزان و دبیران.
- اطلاعیه‌ها و بلاگ با محدوده انتشار مدرسه/پایه/کلاس، ثبت، ویرایش و حذف.
- برنامه هفتگی، برنامه روزانه، بانک سؤال و مدیریت آزمون.
- شرکت در آزمون، جلوگیری از شرکت مجدد هم‌زمان، ذخیره موقت پاسخ‌ها در مرورگر، زمان‌سنج، تصحیح خودکار سؤال‌های عینی و امکان ثبت نمره سؤال تشریحی توسط دبیر سازنده آزمون یا مدیر.
- فرم فعالیت و مطالعه دانش‌آموز با چند ردیف درس و محدودیت مالکیت داده.
- گزارش کلاس، کارنامه با محاسبه نمره و ضریب در Backend، مسئولیت‌ها، اطلاعات مالی و انضباطی.
- مدیریت پایه تنظیمات صفحه اصلی، رسانه‌های تصویری و PDF با بررسی نوع/حجم، گزارش رویدادها و آمار پایه.
- پشتیبان‌گیری از SQLite و فایل‌های بارگذاری‌شده، اعتبارسنجی پایگاه داده در بازیابی و نگهداری حداکثر ۱۰ نسخه اخیر.
- ابزار واردسازی داده JSON از نسخه قدیمی Cloudflare Worker در `legacy_import.py`.
- بروزرسانی دوره‌ای سبک هر ۲۰ ثانیه؛ در صورت وجود فرم فعال/تغییرات واردشده، بازسازی صفحه به تعویق می‌افتد.

## فایل‌ها و داده‌ها

- پایگاه داده: `database/school.db` (پس از اولین اجرا ساخته می‌شود)
- فایل‌ها: `uploads/images` و `uploads/documents`
- گزارش سرور: `logs/server.log`
- نسخه‌های پشتیبان: `backups/`
- قالب کاربران: `users_template.xlsx` و `users_template.csv`

تهیه پشتیبان دستی:

```bash
# Windows
python backup.py

# Linux
python3 backup.py
```

بازیابی (سرور را ابتدا متوقف کنید؛ قبل از جایگزینی، برنامه از دیتابیس فعلی نسخه ایمنی می‌سازد):

```bash
python backup.py restore backups/school-backup-YYYYMMDD-HHMMSS.zip
```

برای پشتیبان‌گیری خودکار، اجرای روزانه `auto_backup_windows.bat` در Task Scheduler ویندوز یا `auto_backup_linux.sh` در cron لینوکس تنظیم شود. اجرای فایل‌های auto-backup به‌تنهایی یک بار پشتیبان می‌سازد و زمان‌بندی را خودکار نصب نمی‌کند.

## استفاده در شبکه داخلی

سرور به‌صورت پیش‌فرض روی `0.0.0.0:8080` گوش می‌دهد. IP داخلی لپ‌تاپ را در مرورگر سایر دستگاه‌های شبکه مدرسه با پورت `8080` وارد کنید. در فایروال فقط شبکه خصوصی مدرسه را مجاز کنید. همه دستگاه‌ها باید به همان شبکه محلی وصل باشند.

**این نسخه برای انتشار مستقیم روی اینترنت عمومی آماده نیست.** HTTPS، reverse proxy، سخت‌سازی سیستم‌عامل، محدودسازی شبکه، آزمون نفوذ و سیاست نگهداری/حفاظت داده باید پیش از دسترسی عمومی انجام شوند. پورت 8080 را مستقیماً روی مودم به اینترنت فوروارد نکنید. تونل یا دامنه به‌تنهایی امنیت ایجاد نمی‌کند و ممکن است در شبکه ایران در دسترس نباشد.

## انتقال اطلاعات نسخه Cloudflare

ابتدا از داده‌های قبلی یک خروجی JSON بگیرید و فایل را در پوشه پروژه قرار دهید. سپس، در حالی که سرور محلی متوقف است، اجرا کنید:

```bash
python legacy_import.py schoolData.json
```

این ابزار فقط ساختارهایی را که در فایل خروجی قابل تشخیص‌اند منتقل می‌کند. بعد از انتقال، تعداد رکوردها را بررسی و پیش از استفاده واقعی یک پشتیبان تهیه کنید. فایل اصلی Worker را حذف نکنید.

## گزارش آزمون‌های اجراشده در ساخت این بسته

- کامپایل همه فایل‌های Python با `py_compile`: موفق.
- بررسی نحو JavaScript با `node --check`: موفق (Node فقط برای آزمون توسعه استفاده شده و پیش‌نیاز اجرا نیست).
- آزمون HTTP: ورود، اجبار تغییر رمز، ساخت کلاس و کاربر، اطلاعیه، برنامه هفتگی، برنامه روزانه، سؤال، آزمون، گزارش کلاس، مسئولیت، فرم فعالیت، کارنامه، آمار و پشتیبان‌گیری: موفق.
- آزمون جریان آزمون: شروع آزمون، دریافت سؤال بدون افشای پاسخ صحیح، ارسال پاسخ، مشاهده پاسخ‌نامه و تصحیح تشریحی: موفق.

این آزمون‌ها در محیط توسعه لینوکس انجام شده‌اند؛ اجرای عملی روی Windows 7 و لپ‌تاپ واقعی 1.25GB RAM هنوز جداگانه تأیید نشده است.

## محدودیت‌های شناخته‌شده و کارهای پیش از بهره‌برداری واقعی

- بخش چیدمان فعلاً تنظیمات محتوای پایه را دارد؛ ویرایشگر کشیدن‌و‌رهاکردن ترتیب بلوک‌های صفحه اصلی پیاده‌سازی نشده است.
- اتصال تصویر/پیوست به تک‌تک اطلاعیه‌ها و پست‌های بلاگ هنوز کامل نیست؛ فایل‌ها در بخش رسانه مدیریت می‌شوند.
- تاریخ‌ها در پایگاه داده به‌صورت رشته استاندارد ذخیره می‌شوند؛ ورودی تاریخ شمسی مستقل و مبدل کامل تقویم جلالی در این نسخه وجود ندارد.
- زمان‌بندی خودکار پشتیبان باید با ابزار زمان‌بندی سیستم‌عامل تنظیم شود.
- گزارش‌های آماری و خروجی Excel برای همه گزارش‌ها هنوز به اندازه خروجی کاربران گسترده نیست.
- ویرایش و حذف فرم فعالیت فراهم است؛ ویرایش/حذف مستقیم کارنامه، اصلاح سوابق آزمون پس از تصحیح و برخی گردش‌کارهای مدیریتی پیشرفته نیازمند توسعه تکمیلی هستند.
- آزمون‌های هم‌زمانی، فشار چندده‌کاربره، مصرف RAM روی سخت‌افزار هدف، بازیابی کامل روی Windows 7 و ممیزی امنیتی مستقل هنوز انجام نشده‌اند. بازیابی نسخه پشتیبان در محیط توسعه Linux آزمایش شده است.
- این سرور HTTP ساده برای شبکه داخلی مورد اعتماد طراحی شده، نه میزبانی عمومی اینترنت.

قبل از وارد کردن اطلاعات واقعی دانش‌آموزان، رمزهای اولیه را امن تحویل دهید، فایروال را محدود کنید و نسخه پشتیبان مستقل روی حافظه جداگانه نگه دارید.
